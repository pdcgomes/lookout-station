## What is Lookout Station?

Lookout Station turns your iPad or Mac into an always-on information display. Compose personal or professional dashboards from 60+ modular panels — weather, calendar, RSS, live sports, server monitoring, smart home controls, trading charts, CCTV feeds, and more — arranged freely on a 24-column grid with drag-and-drop editing.

**Key features:**

- **60+ panel types** covering weather, news, finance, aviation, transit, social media, productivity, entertainment, health, space, gaming, and developer tools
- **50+ themes** from sci-fi command centres to minimalist wireframes, plus a full Theme Studio for creating your own
- **GPU-accelerated cinematic effects** — CRT scanlines, holographic interference, VHS tracking, rain streaks
- **Smart home native** — first-class HomeKit and Home Assistant integration with floor plans, device grids, and scene launchers
- **Kiosk mode** — auto-launch, screen-lock prevention, and scheduled page rotation for always-on wall displays
- **Fleet Commander** — project a single dashboard to multiple iPads across your local network
- **iCloud sync** — dashboards sync seamlessly across devices
- **AirPlay & Cast** support for external displays

## About This Repository

This repository is the public issue tracker and feedback hub for Lookout Station. It does not contain the app's source code.

Use it to:

- **Report bugs** — something broke, crashed, or doesn't look right
- **Request features** — a panel type, theme, integration, or workflow you'd like to see
- **Share feedback** — general impressions, UX suggestions, or ideas

### Submitting an Issue

1. [Search existing issues](https://github.com/pdcgomes/lookout-station/issues) to check if your report has already been filed
2. [Open a new issue](https://github.com/pdcgomes/lookout-station/issues/new) and pick the appropriate template
3. Include as much detail as possible — steps to reproduce, screenshots, and the diagnostics block the app attaches automatically

### Labels

| Label | Meaning |
| --- | --- |
| `bug` | Something is broken or behaving unexpectedly |
| `enhancement` | A new feature or improvement to an existing one |
| `feedback` | General feedback, impressions, or suggestions |

## In-App Reporting

Lookout Station includes a built-in feedback reporter. On iPad, tap the feedback button in the dashboard picker toolbar. On Mac, go to **Settings > About > Send Feedback**, or open the command palette and search for "Report a Bug". The app automatically attaches device info, OS version, and memory diagnostics to help us reproduce issues faster.
